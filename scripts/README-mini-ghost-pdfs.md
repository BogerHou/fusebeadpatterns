# Mini Ghost reading charts

These eight new English, German, French and Japanese A4 / US Letter PDFs use the existing independently authored Ghost silhouette. They do not add a catalog design or rewrite any published pattern. The chart has 29 x 29 numbered cells, 311 beads (293 White, 18 Black), and W / B symbols. Printed cells are deliberately 4.5 mm for legibility; these are counting references, not actual-size Mini pegboard placement templates.

Use `build-mini-ghost-pdfs.py --pack <reviewed-mini-sourcepack>` only after the source-pack and its actual editor project have passed review. Creation refuses an existing `pdfs` directory and opens every PDF exclusively. All eight outputs are written beneath `pdfs/{en,de,fr,ja}/pattern-{a4,letter}.pdf`. Copy only these new files to `public/guides/mini-perler-beads/ghost-mini`, with the English pair at the root and the other three pairs beneath their locale directories.

The PDF builder checks the original Ghost's independently frozen decoded RGBA SHA256 and verifies the Mini project's 57 x 57 grid with the same 29 x 29 image centered by 14 blank rows and columns. It checks page size, language, font embedding, glyph coverage, all 311 colored cells and symbols, all 60 grid lines, material counts, and bounded text. `--check-only` reads all eight existing charts without writing them. Independently render every final PDF with Poppler and inspect it before publishing; passing extraction checks alone is insufficient.

The manufacturer identifies White and Black as Mini colors in its [Football Silhouettes project](https://perler.com/blogs/projects/football-silhouettes). Its [Mini board page](https://perler.com/products/mini-beads-large-pegboards-2-ct) specifies that the board is for Mini beads and not standard beads. The existing software palette uses screen approximations. No Mini retail SKU or precise peg pitch is asserted; W / B and the project's PM-WHITE / PM-BLACK are internal identifiers. Do not present the Midi product numbers from the legacy CSV as verified Mini procurement codes.

The English and European copy use the existing calibration font read-only. Japanese text uses a separately named, checksum-pinned OFL font derivative created by `build-mini-ghost-font.py`. To rebuild that font, first write the JSON inventory from `build-mini-ghost-pdfs.py --font-characters` to a task temporary directory, then pass it to the font helper in an isolated checkout where the target font directory does not exist. The helper refuses to replace an existing directory. Its check-only mode must confirm the inventory and pinned font hashes. Existing fonts are never replaced.

The PDF authoring marker required by the active PDF skill must run successfully once immediately before the first create command, with eight expected outputs. Generators do not issue that marker on the agent's behalf. Source creation, PDF creation, automated checks and final visual review are separate operations. No physical assembly, ironing or suitability for hanging is inferred from the digital chart.
