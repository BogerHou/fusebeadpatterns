# Fuse Bead Loom Patterns font

This is an independently named, static weight-400 subset of Google Fonts'
Noto Sans JP, covering the original loom library's fixed EN/DE/FR/JA copy,
localized chart titles and color labels, ASCII instructions and numeric keys.
It is a PDF/raster asset font and is not an arbitrary-user-text UI font.

Official upstream: https://github.com/google/fonts

Immutable revision: `66a36c8c94b1a5d992ee4e7f392fccfe4945767c`

Font: `ofl/notosansjp/NotoSansJP[wght].ttf`

License: `ofl/notosansjp/OFL.txt`, SIL Open Font License 1.1.

The derivative family is **Fuse Bead Loom Patterns**. The original copyright
and OFL license are preserved in `OFL.txt` and in the font's records. The
license text is copied byte for byte from the pinned official source, never
renamed or edited. `source.json` records upstream SHA-256 hashes and the
derivative/character-set hashes. Embedding and redistribution follow the OFL.

The parent generator's explicit `--refresh-font` mode verifies the immutable
source hashes, checks glyph coverage, makes a static weight-400 subset and
renames the derivative's family records. Ordinary builds are offline.
