# Fuse Bead Library Japanese

This is a new, independently named static weight-400 subset of Google Fonts'
Noto Sans JP, licensed under the SIL Open Font License 1.1. It covers current
whole-library Japanese names, fixed print instructions, assembly notes, numeric
symbols and original English manufacturer color references/names.

Official upstream:

- Repository: https://github.com/google/fonts
- Immutable revision: `66a36c8c94b1a5d992ee4e7f392fccfe4945767c`
- Font: `ofl/notosansjp/NotoSansJP[wght].ttf`
- License: `ofl/notosansjp/OFL.txt`

`source.json` records the verified immutable download hashes, subset hash and
character-set hash. The original copyright/license remains in `OFL.txt` and
the font's records; the derivative family is renamed to **Fuse Bead Library
Japanese**. Embedding and redistribution are allowed under that license.

To refresh it, explicitly run the parent generator with `--refresh-font` and
Python `fonttools` available. The complete official font is held in memory;
ordinary sample/library builds run offline from this checked-in subset. Future
characters require a reviewed refresh and PDF reacceptance. This is not a UI
font or an arbitrary-user-text font, and does not replace or alter the existing
`noto-sans-jp` or `public/fonts/fuse-bead-japanese` assets.
