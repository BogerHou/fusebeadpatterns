# Fuse Bead Guide Japanese

A static weight-400 subset of the immutable Google Fonts Noto Sans JP source,
licensed under SIL Open Font License 1.1. Its independent derivative family is
**Fuse Bead Guide Japanese**. The original copyright and license records remain
in the font and in `OFL.txt`.

The subset covers the three existing guide examples, native Japanese print
directions, ASCII manufacturer product names and the original Perler palette
symbols (including their non-ASCII symbols). It is not an arbitrary-user-text
font. Existing editor, library and website fonts are not replaced.

`source.json` records the immutable repository revision, verified upstream font
and license hashes, generated subset hash, character-set hash and fonttools
version. Recreate with `scripts/build-localized-photo-guide-pdfs.py --refresh-font`.
Ordinary builds use the checked-in font offline. The full upstream font is
downloaded into memory and is not kept as a project asset.
