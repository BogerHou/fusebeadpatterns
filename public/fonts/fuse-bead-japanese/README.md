# Japanese PDF font

This is the same renamed, weight-400 Noto Sans JP subset maintained at
`scripts/fonts/noto-sans-jp/`. Source revision and upstream checksums are recorded
there. The SIL Open Font License is included beside the font.

The Japanese generator fetches this file only when exporting a PDF. The font
covers its fixed Japanese print instructions and ASCII brand references; it is
not suitable for arbitrary user-supplied Japanese text.
