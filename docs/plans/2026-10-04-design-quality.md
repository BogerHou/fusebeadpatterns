# 网站设计品质标准与本地改进记录

目标：以 Awwwards、Webby Awards、FWA 级别的设计完成度作为持续改进方向，服务“更多用户找到并完成真正想做的拼豆图案”。获奖由外部评审决定，不用内部打分代替获奖证明。

## 设计原则

- 网站气质：安静、清楚、有手工制作感的拼豆工作室；真实图案是视觉中心。
- 品牌与排版：暖白底、深绿主操作、细分隔线；Manrope 标题与 Inter 正文，数字参数易读。
- 图片准确：不凭空创造角色；首页像素/拼豆对照直接从蓝鸡现有 Perler 工程的 192 个有效单元生成，位置和颜色完全同源。
- 找图方便：普通图片卡只显示图片和名称；分类、搜索、面包屑可直接操作，内容保持可抓取。
- 动效克制：仅一次轻量入场和有意义的状态反馈；尊重 reduced-motion，不锁滚动、不隐藏重要内容等待动画。
- 可访问性：统一键盘焦点、跳到正文、导航当前状态、清楚的表单标签；手机文字输入至少 16px，主要操作至少 44px。
- 信息诚实：真实角色名、数字预览明确标注、保留来源与未经实体制作验证的说明；不添加虚构销量、评价或流量排名。

## 本轮完成范围

1. 首页重排，保留原 H1、结构化数据、生成器和全部说明事实；增加直接进入工作区/图库的入口及真实图案对照。
2. 图库、详情、指南、关于、政策页及公共导航采用一致的排版。图库开头展示四种现有题材，不宣称它们是流量排行。
3. 编辑器调整视觉类与移动表单字号，并为三类模态弹窗补齐初始焦点、Tab 双向循环、Escape 关闭与触发按钮焦点恢复；绘制、品牌转换、存储与导出算法保持不变。首页端到端测试改为通过实际“Make a pattern”入口进入工作区，原功能断言保留，另增加真实键盘弹窗回归。
4. 增加有返回路径的 404 页面，保留错误状态。
5. 改进正文内链接、对比和焦点、搜索空结果、触控与手机筛选密度。
6. 独立审查发现现有 Next 与 DOMPurify 安全公告后，将 Next/ESLint 配置同步补丁至 16.3.8、DOMPurify 锁版本至 3.4.16；未运行 audit force，未跨主要版本升级。

## 保护与验收

- 现有 URL、canonical、标题/描述、H1、结构化数据、100 个图案详情、116 个 sitemap URL、原下载地址和原素材文件必须保留。
- 本地生成器、图库搜索/分类/复位、图案→编辑器→切换品牌→导出流程实测；移动与桌面都检查。
- 最终生产构建必须完成 tests/typecheck/lint/build，并单独执行 HTTP 与编辑器回归。
- SEO 守护以部署版本为基线，比较语义和链接集合，允许合理由视觉改版产生的顺序变化。
- 原始 GSC 数据继续留在被 gitignore 的私有目录，不复制到本文件。
- 此轮只在本地制作与测试，提交、推送与上线需要用户明确提出。

## 评审依据与边界

参考 [Webby 官方评审标准](https://www.webbyawards.com/judging-criteria/) 中对内容、结构导航、视觉、功能、交互和总体体验的要求。Awwwards 与 FWA 作为用户指定的品质方向；未把无法完整抓取的评审页转换成具体分数阈值。

此轮没有跨浏览器真人研究、实体拼豆摄影或外部奖项评审，不能声称完成了这些验证。视觉改版也不是自然流量增长的证据；上线后的效果需要后续真实数据比较。

依赖全量审计仍有 braces 开发依赖链告警，当前上游未提供补丁。生产依赖审计和全量审计必须分别报告，不为了显示通过而修改检查规则。来源：[Next 公告](https://github.com/vercel/next.js/security/advisories/GHSA-vcvr-r3jv-pc5j)、[DOMPurify 公告](https://github.com/cure53/DOMPurify/security/advisories/GHSA-p98j-92pf-mc4p)、[braces 公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)。
